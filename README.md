Osobní stránka **https://stefek.info**, hostovaná na GitHub Pages
(větev `main`, root; doména v souboru `CNAME`, DNS A/CNAME → GitHub Pages).

upravený 2026-11: odstraněny osobní údaje (CV v PDF, telefon, ICQ),
UTF-8, viewport pro mobil, https odkazy.
Podsložka `pavlina/` = obnovená hlavní stránka pavlina.stefek.info (archiv 2022-03).
